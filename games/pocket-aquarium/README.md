# Pocket Aquarium

Pocket Aquarium is the repository's shipping aquarium game and default deployed product.

- Engine and player: [`engine/`](engine/)
- Product documentation: [repository README](../../README.md)
- Ecology model: [Ecology Model](../../docs/ECOLOGY_MODEL.md)
- Android delivery: [Android Deployment](../../docs/ANDROID_DEPLOYMENT.md)
- iOS delivery: [iOS Deployment](../../docs/IOS_DEPLOYMENT.md)

Run the game from `games/pocket-aquarium/engine` with `npm ci` and `npm run dev`.
